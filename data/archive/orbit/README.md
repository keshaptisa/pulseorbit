# Исторические TLE ISS

Положите сюда файл `iss.tle` в стандартном формате TLE. Допускается несколько наборов подряд:

```text
ISS (ZARYA)
1 25544U ...
2 25544  ...
```

Сервис выбирает последний набор с эпохой, не превышающей запрошенное историческое время. Если подходящего файла нет, исторический режим показывает источник как `unavailable` и не подменяет его современным TLE.

Источник и время публикации набора должны быть зафиксированы в исследовательском отчёте. Один только TLE с эпохой не доказывает, что он был опубликован до cutoff.
