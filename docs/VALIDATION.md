# Проверка прогнозного сигнала

## Данные

Проверка связывает прогнозную вероятность протонного события из датированных NOAA `daypre` с последующим наблюдением события потока протонов `>10 MeV` на геосинхронной орбите. Наблюдения взяты из еженедельных отчётов NOAA SWPC PRF и никогда не передаются в replay-расчёт.

- Период целей: 2 мая - 30 июня 2024 года.
- 58 доступных суточных прогнозов, без заполнения пропущенных файлов.
- 7 суток пересекаются с двумя наблюдавшимися событиями, 51 сутки не пересекаются.
- Manifest наблюдений: `data/validation/proton_observations.json`.
- Полная таблица и чувствительность: `data/validation/experiment_summary.json`.

## Результат порога 50%

| Метрика | Значение |
|---|---:|
| TP | 7 |
| FP | 3 |
| FN | 0 |
| TN | 48 |
| Precision | 0.700 |
| Recall | 1.000 |
| Specificity | 0.941 |
| F1 | 0.824 |
| Brier score | 0.0574 |

Для двух начал наблюдавшихся событий последний доступный суточный прогноз выше порога появился за 15.38 и 16.00 часа. Эти значения описывают только проверенный архивный пример и не гарантируют эксплуатационную заблаговременность.

## Ограничения

Выборка содержит два связанных активных интервала и не является полной эксплуатационной валидацией. Метка относится к протонному событию на геосинхронной орбите, а не к дозе конкретного космонавта или разрешению на ВКД. Порог 50% выбран как прозрачное правило прототипа; таблица чувствительности 10-90% сохранена для аудита.

## Воспроизведение

```powershell
python scripts/run_experiments.py
```

Скрипт заново формирует `experiment_summary.json` из сохранённых выпусков и manifest наблюдений.
